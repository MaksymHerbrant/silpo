# Сценарій демо (запис екрана, ~2:30)

**Перед записом:** `DEMO_MODE=false`, реальний акаунт Сільпо з непорожнім кошиком і
кількома онлайн-замовленнями за останні тижні, у профілі Сільпо задане хоча б одне
дієтичне обмеження. Прогнати `scripts/probe_mcp.py --cart` і переконатись, що харчова
цінність приходить (інакше половина товарів буде «н/д»).

| Час | Що показуємо | Що звучить |
|---|---|---|
| 0:00 | Telegram → кнопка меню бота → Mini App відкривається | «Це не бот — це повноцінний інтерфейс усередині Telegram» |
| 0:10 | Екран онбордингу → «Під'єднати Сільпо» → зовнішній браузер → вхід → повернення в Mini App | «OAuth 2.1 + PKCE; токен залишається на бекенді зашифрованим» |
| 0:35 | Головний екран: кільце рейтингу, пояснення, графік БЖУ + доданого цукру | «Нічого не вводили руками — це реальний кошик через MCP» |
| 1:00 | Список товарів, відсортований від найгіршого; підсвічений товар з високим цукром; товар з бейджем «н/д» | «Товари без харчової цінності ми не рахуємо нулями, а чесно позначаємо» |

## Обов'язкові докази для журі

1. `tools/list` — кнопка на екрані «MCP-лог».
2. Кілька read-tools: `silpo_get_my_shopping_cart`, `silpo_get_shopping_cart_by_id`,
   `silpo_get_time_slots`, `silpo_get_product_details`, `silpo_get_my_food_restrictions`,
   `silpo_get_similar_products`, `silpo_get_my_online_orders`.
3. Один write: `silpo_add_or_update_cart_products` — видно в логу як останній виклик.
4. Ендпоінт лише `https://mcp.silpo.ua/mcp` (він же надрукований угорі екрана логу).

## Метрика для пітчу

`GET /swaps/suggestions` повертає `stats` — скільки замін запропоновано, скільки прийнято,
і **% прийнятих свопів**. Це прямий показник цінності продукту: не «користувач подивився
графік», а «користувач змінив покупку».

## План Б, якщо на демо впаде мережа або rate limit

- `DEMO_MODE=true` піднімає той самий флоу на фікстурах (`backend/app/mcp/fixtures.py`),
  включно з логом JSON-RPC. Екран логу в цьому режимі показує бейдж **DEMO** — не видавай
  його за живий виклик, це запасний варіант лише для показу UX.
- Заздалегідь зроби скрінкаст живого сценарію: за 429 backoff може додати кілька секунд
  очікування на кошику з 20+ товарів.
